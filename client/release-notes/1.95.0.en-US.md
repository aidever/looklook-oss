Looklook desktop 1.95.0: custom listening port support for easier firewall, port-forwarding, and reverse-proxy setup.

- New: set a custom listening port directly in "Settings → Network & access". Looklook checks whether the port is in use or needs privileges before saving; leave it empty to return to automatic selection.
- New: after changing the port, restart Looklook in one click from the page to apply it (running terminals are not interrupted), and local/LAN tabs redirect to the new port automatically. If a custom port is busy at startup, Looklook falls back to a free port so you're never locked out.
- New: CLI command `looklook access port <port|auto>` to set or reset the listening port.
