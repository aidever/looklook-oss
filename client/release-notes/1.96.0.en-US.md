Looklook desktop 1.96.0: shared computer support, docked side-chat panel, official account sign-out, and chat/assistant improvements.

- New: shared computer support and offline authorization codes; plugin hooks for operator signatures and read-only Feishu group questions.
- New: side chat (`/btw`, `/side`) now opens in a right-hand docked panel and can be started directly from selected text in AI replies; mobile AI replies use native text selection with a bottom action bar.
- New: the docked file viewer on desktop supports drag-to-resize, zoom, fullscreen, and opening in a new tab.
- New: Antigravity (`agy`), Claude Code, and Codex official accounts (including when only the default local account is present) can now be signed out from the account list and `/logout`, with login status shown for Codex's local default account.
- Improvement: chat permission mode changes now persist, including switching permissions mid-approval in Codex; the assistant can adjust permission modes, models, reasoning effort, and queued tasks on dispatched and runner sessions, and runner sessions allow manual permission switching.
- Improvement: refined settings page UX and Markdown table layout (fixing file-link columns wrapping one character per line); direct connection setup filters Docker virtual bridges, unifies addresses and multi-certificate SNI settings, and supports picking certificates from a directory.
- Fix: assistant default permissions, model, and reasoning effort not applying to runner and Codex dispatched sessions; bare `/btw` without a question being sent as a normal message; short text in "send after this turn" showing scrollbars.
