Looklook desktop 1.80.0: the chat view can now fully replace Claude Code / Codex in the terminal, and the Terminal tab is back to being a plain shell.

- A session's Terminal tab is now an ordinary shell in the project folder. Run your own commands there; it no longer syncs or hands off with the chat.
- Everything you could do in the terminal now works in chat:
  - `!command` runs a command and records it in the conversation; `/btw` (`/side` in Codex) asks a side question without interrupting the current work; a running command can be moved to the background.
  - The settings panel edits things directly: permission rules, extra directories, MCP (status, toggle, reconnect, sign in and out; when opened remotely, paste back the address you land on after signing in), adding and removing hooks, the sandbox switch, creating and deleting subagents, plugins and plugin marketplaces.
  - `/memory` opens CLAUDE.md for editing, with a Create button when it doesn't exist yet.
  - `/skills` opens skills right in the chat: this project's skills (view only) and the ones installed on this computer (delete and undo).
  - `/login` and `/logout` open account management in the chat: sign in, sign in again, add accounts, and switch this conversation to another account; Codex signs in with ChatGPT or an API key right there.
  - Plus `/status`, `/fork`, `/diff`, `/feedback`, `/release-notes` and more; Codex gains `/review`, `/goal`, `/fork`, `/init`, `/rename`, `/archive`, `/delete`, `/stop`, `/experimental`, and plugin and hook lists.
- "Send now" is fixed: it really brings queued messages in right away (Claude decides whether to move the running command to the background or stop the turn). The button locks on the first click and shows a spinner, so double clicks send once.
- The same conversation no longer opens as several sessions, and the sidebar no longer lists it twice.
- New-session page on phones: the input stays on one line with the send button always visible; @, skills, attachments and templates are in a single ＋ menu.
