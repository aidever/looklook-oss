看看电脑端 1.88.0：重写 Antigravity（agy）对话模式，远程浏览器插件改为单独开通，以及助理与本机连接的改进。

- Antigravity（agy）对话模式重写，更稳定：运行中发的消息自动排队，审批、停止、切换模型和思考强度、随时切换权限模式都在看看里完成，重新打开会话时完整恢复历史记录。
- 用量统计加入 agy，按 models.dev 上 Google 的公开价格折算费用；“AI 工具版本”可以检查 agy 的新版本并一键更新（`agy update`），也支持自动更新。
- 远程浏览器插件需要单独开通（不包含在会员里，开通时有到期时间）：已经装过旧版插件的请在“工具 → 插件”里重新安装，浏览器配置和登录状态都会保留。插件页会显示授权状态，授权到期后浏览器暂停使用。
- 在对话里点链接、选择用远程浏览器打开时，插件页会直接显示启动进度；还没安装或还没开通时会记住这个链接，装好后启动即可打开。
- 助理派出去的会话可以手动切换到任意权限模式；设置里可以按引擎（Claude Code / Codex）设置默认权限和默认模型。
- 桌面 App 连接本机的会话时直接走本机连接，不再经过中转协商，打开更快。
