Looklook desktop 1.88.0: a rewritten Antigravity (agy) chat mode, a separately licensed remote browser plugin, and assistant and local connection improvements.

- Rewrote the Antigravity (agy) chat mode for reliability: messages sent during a turn are queued, and approvals, stopping, switching model and thinking level, and changing the permission mode at any time all work inside Looklook; reopening a session restores its full history.
- Usage stats now include agy, with costs estimated from Google's public prices on models.dev; AI Tool Versions can check for new agy versions and update with one click (`agy update`), including auto-update.
- The remote browser plugin now requires a separate license (not included in membership, granted with an expiry date). If you installed the earlier plugin, reinstall it from Tools → Plugins; browser profiles and sign-ins are kept. The plugin page shows the license status, and the browser pauses once the license expires.
- Opening a chat link in the remote browser now shows the browser's startup progress on the plugin page; if the plugin isn't installed or licensed yet, the link is remembered and opens once you start the browser.
- Sessions dispatched by the Assistant can be switched to any permission mode by hand, and Settings lets you set the default permission and default model per engine (Claude Code / Codex).
- The desktop app now connects to sessions on the same computer directly instead of negotiating through a relay, so they open faster.
