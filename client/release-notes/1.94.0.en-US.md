Looklook desktop 1.94.0: assistant memory rebuilt; connection settings on one page that picks the fastest path; risk warnings for Claude links.

- New: assistant memory rebuilt. Memory is now a set of note pages (about you, per project, misc) the assistant reads and writes itself. Each night it tidies them against what was actually said that day, with a reason for every change, and you can undo a whole tidy-up. The memory page is redone too: full text, history and sources, plus edit, create, delete and forget for good.
- New: "Settings → Network & access" is now a single "Connection & speed-up" page. With no setup, Looklook takes the fastest path: this computer → LAN → tunnel / IPv6 / public direct → P2P → relay as fallback. Add a Cloudflare Tunnel, frp, reverse proxy or DDNS address to prefer it, or use your own HTTPS certificate.
- New: clicking claude.ai, anthropic.com and similar links in the terminal or chat shows a red warning first: open them in your bound fingerprint browser, confirm again to open locally, and a reminder on copy not to paste them into apps like Feishu that fetch link previews. Can be turned off in Settings.
- New: third-party providers get a Test button that shows the provider's own error on failure; pick models from the provider's list; Claude gains a Fable slot, and Codex can map model names to the provider's models.
- New: sessions the assistant dispatches can have a thinking effort (defaults per Claude Code / Codex in Settings); if you say how hard to think, that wins.
- New: Antigravity chats get a Gemini-style theme.
- Improved: when Antigravity runs out of quota, it carries on automatically at the stated reset time, even after a client restart; the card shows when it will continue and offers "Don't auto-continue".
- Improved: Looklook opens on the home page instead of jumping to the assistant; the logo at the top left goes home.
- Improved: AI tool auto-update toggles respond instantly.
- Fix: reopening an existing Antigravity session briefly flashed the new-session page.
- Fix: a batch of assistant memory and dispatch issues (duplicate memory entries, "about you" sync overwriting between computers, sessions stopped by mistake when woken by an event, and more).
