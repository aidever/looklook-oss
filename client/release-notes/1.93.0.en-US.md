Looklook desktop 1.93.0: check and use limit resets right in Looklook; Antigravity gets multiple accounts, automatic switching and auto-compact.

- New: the Usage panel in a chat lists your limit resets; tap Use and confirm to clear the limit right away. Codex shows each reset and when it expires; Claude Code shows them by kind (Fable, full, 5-hour, weekly) — Looklook runs Claude Code's own /limit-reset for you in the background, with no window, and always asks before using one.
- New: new Antigravity sessions can pick an account automatically (the one with the most quota left); when a turn fails because quota ran out, switch to another account and carry on in one tap, or let it switch automatically.
- New: Antigravity model settings have an auto-compact point; in chat mode Looklook sends /compact for you when it's reached.
- Fix: logged-in Antigravity accounts showed "Log in"; quota, plan and context window now show correctly.
- Fix: a chat session you once switched to Terminal kept opening in the terminal.
- Fix: in third-party providers, the model label overlapped the environment variable name.
