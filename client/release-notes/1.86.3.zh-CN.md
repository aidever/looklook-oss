看看电脑端 1.86.3：浏览器页能换设备，助理页能一键装好 Claude Code / Codex。

- 远程浏览器页顶栏现在可以直接切换设备，不用先回别的页面再切。
- 助理还没开通、电脑上又没装 Claude Code 或 Codex 时，开通页里多了“一键安装”：没有 Node.js 也会先装好，步骤和进度就在页面里看。
- 会话栏顶上多了“浏览器”标签，和“会话”“SSH”并列：列出这台电脑的浏览器配置，在运行的有标记，点一下进浏览器页。
- 手机上的浏览器页也有“在新标签页打开”按钮了。
- 在新标签页里打开的浏览器画面，顶上有个小胶囊显示连接情况（本机/远程、延迟、丢包），点它回浏览器管理页；全屏时也能看到连接状态。
