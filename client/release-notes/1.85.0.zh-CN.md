看看电脑端 1.85.0：在 Linux 服务器上开一个浏览器，远程直接用。

- 新增「浏览器」（左边栏、会话栏顶上、手机“我的”里都有入口）：在这台 Linux 电脑上运行一个有界面的浏览器，画面推到看看里来用；打字、中文输入、复制粘贴、上传下载、声音都可以，关掉页面浏览器也继续开着。
- 默认不装，第一次用时在页面上安装（下载约 190 MB）。下载源自己选：官方 GitHub 或几个 GitHub 加速，可以先测延迟和速度；安装前核对文件校验值。
- 缺系统库、缺中文字体时会列出来并给出一行安装命令，用 root 运行看看时可以直接点“帮我装”。
- 可以建多套配置，每套是一份独立的浏览数据和“指纹”：模拟 Windows / macOS / Linux、浏览器品牌、CPU 核数、内存、屏幕、语言、时区、地理位置、代理（支持带用户名密码）、WebRTC、Canvas / WebGL / 音频随机化、摄像头麦克风、语音列表等，方便在服务器上复现用户那边的环境。同一时间只运行一套（一套就要 1 GB 以上内存）。
- “没人看时自动关闭”是开关，默认关。
- 目前只支持 x86_64 的 Linux 电脑；Windows、macOS 电脑上不显示这个入口。
