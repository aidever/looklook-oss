Looklook desktop 1.90.0: faster direct connections on your own domain, crisper text in light themes.

- New: when a computer has public HTTPS direct access enabled, opening it through your own domain now connects to it directly instead of setting up a peer-to-peer connection, so it opens faster and more reliably; if the direct connection fails, it falls back to the usual way automatically.
- New: connect to remote fingerprint browsers with a key.
- Improved: the link hover menu now offers the same actions in terminals and chats.
- Fixed: in light themes, terminal text looked bolder and blurrier than page text (most noticeable on Windows).
- Fixed: after an update, an old page could fail to load with a module script error; it now reloads to the new version automatically.
