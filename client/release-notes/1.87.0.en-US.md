Looklook desktop 1.87.0: full Antigravity CLI (agy) support, a general plugin system, and remote connection and chat improvements.

- Added full Antigravity CLI (agy) support: create and manage agy sessions with the native chat UI, plus MCP, Skills, one-click update checks, and usage stats on the AI Tools page.
- Added a general plugin system (Tools → Plugins): the remote browser is now an optional installable plugin, and existing browser profiles and data from earlier versions migrate automatically on first launch.
- When enabling the Assistant on a computer without Claude Code or Codex, the setup page now offers a one-click install (installing Node.js first if needed); approval cards refresh immediately after approving, and assistant processes stop cleanly when Looklook exits.
- Codex chat on macOS can now use `@Chrome` / `@Browser`; press `⌘/Ctrl + Enter` while a turn is running to queue the next message (or make queuing the default); model and reasoning-effort switches respond immediately.
- The text-selection toolbar is now a bubble above the selection (falling back below when space is tight); switching computers refreshes the AI Tools, Files, SSH, Pages, and System drawers for the selected computer.
- Remote connections can now be set to "Direct only" per computer (skipping STUN/TURN so IP-based proxy rules such as Clash work), and static assets race a mirror source for faster loading.
- Moved the open-source repository to github.com/aidever/looklook-oss.
