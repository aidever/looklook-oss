Looklook desktop 1.84.0: a more complete memory for the assistant.

- It can look things up in past conversations: ask "how did we fix that bug last time?" and it searches all your earlier conversations with it and the Claude Code / Codex sessions on this computer. You can search the same way in the Memory tab.
- It fills in what it missed: when idle it reviews recent conversations, and once a day it tidies up (merges duplicates, moves misfiled entries). Anything touching entries you wrote or pinned waits for your OK. You can turn this off.
- On first use it lists the projects you work in; one tap adds them to the project roster, where you can give a project your own name ("the shop backend") so the assistant knows which one you mean.
- The conversation stays one thread: when the context fills up it is tidied in place (a divider marks the spot), and after a night away it picks up with fresh memories.
- "About you" syncs across your computers; you can turn sync off on a work computer.
- Every memory has a history you can go back to; "Forget for good" deletes it with its history; the "Remembered" line in the chat has an Undo. Memories and conversation records can be exported as a zip.
