Looklook desktop 1.86.0: scrolling and selecting text in the terminal on phones now works like a normal web page; a new remote browser engine; permission levels for sessions the assistant starts.

- Swiping back through terminal output on a phone now follows your finger and keeps gliding when you let go, instead of jumping in steps. A "back to bottom" button appears while you're scrolled up.
- Select text right in the phone terminal: long-press selects the whole line under your finger, drag the handles to adjust, and copy or share from the system menu. Double-tap selects a word, triple-tap a line, and the selection stays put while you scroll. The old "Select text" panel is still in the top bar.
- On phones the soft keyboard only opens from the key bar's keyboard button; tapping or swiping the terminal no longer pops it up.
- Swiping now scrolls inside full-screen programs like less and man on phones.
- The remote browser now runs on Camoufox and presents itself as a real recorded computer; time zone, language and location follow the exit IP automatically. It moved into the tools menu, the header shows which computer it runs on and its resource use, and common setups are one tap away.
- Remote browser: shows progress while starting; closing the last tab no longer quits it; if it's opened somewhere else you get a notice and can take it back; sound works now; the view no longer disconnects over a remote (WebRTC) connection.
- Sessions the assistant starts get one of four permission levels — read only, ask before acting, free within the project, full access — separate from the assistant's own. The assistant picks one per task under a limit you set (default: free within the project) and asks before going higher; you can change a session's level from the activity panel.
- When a session the assistant started needs your approval, handle it right on the assistant page: a "needs you" bar above the chat, and allow / allow for this session / deny / answer in the activity card. For tasks given over Feishu, approvals go to your Feishu DM.
- The assistant now passes on only the parts of your message that matter for each task, and queued Looklook notices show as one-line cards.
- Back button: on phones, entering a session from the assistant or new-session page, both back and the top-left arrow return to the session list; the bottom sheet for dropdowns and the quick switcher close with back.
- On desktop, session rows, file rows and chat messages now have right-click menus.
- Codex fast mode: a "Fast" switch in the chat settings bar, plus `/fast on|off|status`. It needs a ChatGPT login and a model with a fast tier; otherwise you're told why. Auto-compact points can be set in model settings.
- The usage panel computes context against the auto-compact point, matching the ring by the input box, and shows the maximum context.
- The session list has "Sessions / SSH" tabs; SSH sessions are grouped by host, and all saved hosts are listed.
- When sessions are grouped by project, each project shows up to 10; the rest fold into "N more", which expands in place.
- The phone bottom bar is now Assistant · Sessions · + · Tasks · Me; Tasks no longer repeats under Me.
- Links in chat can open in the Looklook browser, and it remembers your choice.
- Mermaid diagrams can be enlarged: full-screen view, wheel or pinch zoom, drag, fit to screen, and copy source or download SVG.
- The model menu is unified: effort levels show only those the model supports, and Fast is inside the menu.
- The remote browser sets time zone and language from the exit IP automatically; the device supplies the rest.
- Fixed saved-password SSH login failing on Windows.
- The assistant's MCP page now works remotely too: view and replace the token, and install or remove the assistant. Remote actions require two-step verification; they're no longer limited to the local machine.
- Fixed Markdown tables squeezing the first column into one character per line.
