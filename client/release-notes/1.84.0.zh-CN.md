看看电脑端 1.84.0：助理的记忆更完整了。

- 记过的事能搜到以前的对话：问助理“上次那个 bug 怎么修的”，它会搜你们以前的全部对话、这台电脑上的 Claude Code / Codex 会话；助理页「记忆」里也能直接搜。
- 助理会自己补记：空闲时回看最近的对话补上漏记的，每天整理一次（合并重复的、挪放错类的）；动到你写的、钉住的，先放进“等你点头”。可以关掉。
- 第一次打开会列出你常用的项目，点一下加进“项目名册”；你可以给项目起自己的叫法（比如“商城后端”），助理靠它认出你说的是哪个。
- 对话一直是一条：上下文快满时自动整理（界面上留一条分隔线），隔了一夜再用会带上最新的记忆接着聊。
- “关于你”在你的几台电脑之间同步，公司电脑可以单独关掉。
- 每条记忆能看历史版本、回到某一版；不想留的可以“彻底忘掉”（连历史一起删）；对话里“记住了”那一行能直接撤销。记忆和对话记录可以导出成一个 zip。
