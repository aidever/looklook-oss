Looklook desktop 1.80.3: the safety net now says who stopped a command and which rule, every built-in rule can be switched off on its own, and changes apply right away; chat sessions can be renamed.

- When the safety net asks you to confirm a command, the card now says it was stopped by Looklook's safety net and names the rule — built-in or one you added — with an "Adjust safety net" link right there.
- AI → Tools → Safety net: under "Confirm dangerous commands" you now see every built-in rule (git push --force, git reset --hard, git clean -f, DROP TABLE and more), each with a short explanation and its own switch. A rule you turn off no longer asks you; the rest still do, including the other steps of a chained command.
- Safety net changes apply right away, no need to restart sessions. Commands already waiting for you follow the new rules too: turned off means it runs, changed to deny means it is denied.
- The More menu of a chat session in the session list now has Rename. It renames the conversation itself, so the new name shows in the session list, the chat title and past conversations, and auto-generated titles no longer replace it.
- Typing just `/rename` in a chat opens the rename box; `/rename new name` renames right away. Works for both Claude Code and Codex.
