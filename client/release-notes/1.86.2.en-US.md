Looklook desktop 1.86.2: one-click install for Claude Code and Codex, and a better remote browser on phones.

- Install Claude Code and Codex in one click even without Node.js: Looklook first installs Node.js into its own folder, no admin rights needed. The download source is picked automatically.
- Claude Code now uses the official installer and falls back to npm if it can't be reached.
- When the npm global folder isn't writable (the common EACCES error on Linux), tools are installed into Looklook's own folder, and later updates go there too.
- Tools that aren't installed can now be installed straight from AI tool versions, and an "Install all" button sets up Node.js, Claude Code and Codex in one go, with each step and its progress shown right there.
- On phones, after zooming into the remote browser, turn on "Move view" to drag around the page with one finger.
- The Browser entry in the Me and Tools menus is always there instead of disappearing when you switch devices; on computers that don't support it, the page explains why.
- The browser install page no longer asks you to pick an engine, components or a download source. It installs step by step and adds missing system libraries automatically (needs root or passwordless sudo).
