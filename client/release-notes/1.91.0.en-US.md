Looklook desktop 1.91.0: a big file-management overhaul — see more, edit safely, and open files mentioned in chat with one click.

- New: file paths in chat replies (including ones with line numbers like `a.rs:12`) become links that jump to that line; paths outside the working directory are labelled.
- New: on desktop, files opened from chat dock on the right so you can read while you chat, with up to 8 tabs; edit cards can open the diff directly.
- New: compare a file with its version before the chat or before this turn, and send selected lines to the chat as a comment.
- New: GBK and other encodings are opened and saved in their original encoding, keeping line endings and BOM; you're asked first when a character can't be saved.
- New: you're warned if a file changes elsewhere while you edit (diff, use disk version, keep mine); unsaved edits can be restored after a reload; read-only views refresh when the file changes.
- New: large files open in segments (with go-to-line); previews for JSON trees, Jupyter notebooks, archives (browse and extract), hex, and web pages (with styles and scripts); PowerPoint and legacy doc / ppt / xls too.
- New: icon view with image and video thumbnails in the file list; new file; copy relative path; very large folders load in batches.
- Improvement: editing on phones has a key bar above the keyboard; editing Markdown on desktop shows a live side-by-side preview.
- Fix: the phone terminal occasionally re-sent text already typed; keyboard buttons were slow under agy.
- Fix: opening a chat session flashed the terminal first; the model menu was wrong after signing in to OpenAI in a third-party-API Codex session.
- Fix: menus on the chat page didn't respond to macOS trackpad taps; one-click Antigravity install failed.
- Change: OpenCode and DSH are no longer supported.
