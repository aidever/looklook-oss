Looklook desktop 1.86.3: switch devices on the Browser page, and set up Claude Code / Codex from the Assistant page in one click.

- The remote Browser page now has a device switcher in its header, so you no longer need to go to another page first.
- If the Assistant isn't enabled yet and Claude Code or Codex isn't installed, the setup page now offers a one-click install. Node.js is installed first when missing, with steps and progress shown right there.
- The side list now has a "Browser" tab next to "Sessions" and "SSH": it lists this computer's browser profiles, marks the running one, and opens the Browser page on click.
- The Browser page on phones now has the "Open in new tab" button.
- A browser opened in its own tab shows a small pill with the connection (local/remote, latency, packet loss) and a link back to the Browser manager; the connection status is also visible in full screen.
