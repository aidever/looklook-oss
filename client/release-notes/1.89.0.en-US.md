Looklook desktop 1.89.0: a new terminal engine, rebuilt terminals on phone and desktop, opening sessions in your own terminal app, and easier direct connections.

- New terminals use Looklook's own terminal engine by default: sessions keep running in the background and survive Looklook restarts and updates, and less data is sent to phones and browsers, so weak networks feel smoother. Terminals that were already running before the update keep working the old way and are tagged "legacy" at the top of the session; you can turn the new engine off in Settings.
- Rebuilt terminal on phones: selecting text and scrolling feel better, and the screen no longer jumps when the keyboard opens or closes.
- The desktop terminal now draws with the GPU: text stays crisp at non-100% display scaling, with smooth local scrolling and text selection.
- On slow networks, what you type shows up right away instead of waiting for the round trip.
- Dragging files onto the new terminal still uploads them (trzsz).
- The desktop app can open a session in a terminal app installed on this computer: Ghostty, iTerm2, WezTerm, kitty, Alacritty, Terminal, Windows Terminal and more. Pick "Open in …" from the terminal menu, or set one as the default in Settings so opening a session pops up that terminal. Sessions on your other computers can be opened this way too. Scrolling, search and selection are that terminal's own, and closing the window leaves the session running.
- Output from legacy terminals is compressed too, so opening and paging are faster on weak networks.
- New "Public HTTPS direct" (Settings → Direct): a computer with a public IP can get its own certificate and be opened directly in a browser without going through a relay.
- Settings → Direct now checks this computer's network type and whether its ports are reachable; connection details explain why a connection is going through a relay.
- Direct connections on the same local network succeed more often; with several computers, each one's connection status is shown separately and can be reconnected on its own.
- Fixes: plugin pages opened blank; "Direct only" never took effect; on phones the send button needed two taps.
