Looklook desktop 1.85.0: run a browser on your Linux server and use it remotely.

- New "Browser" (in the left rail, at the top of the session pane and under "Me" on phones): runs a full browser on this Linux computer and streams it into Looklook. Typing, IME input, copy & paste, uploads and downloads, and sound all work, and it keeps running after you close the page.
- Not installed by default: install it from the page the first time (about 190 MB). You pick the download source—official GitHub or a few GitHub mirrors—and can test latency and speed first; checksums are verified before installing.
- Missing system libraries or CJK fonts are listed with a one-line install command; when Looklook runs as root you can just click "Install for me".
- Create several profiles, each with its own browsing data and fingerprint: pose as Windows / macOS / Linux, browser brand, CPU cores, memory, screen, language, time zone, location, proxy (with username/password), WebRTC, Canvas / WebGL / audio noise, camera & microphone, speech voices and more—handy for reproducing your users' environment on a server. Only one runs at a time (each needs over 1 GB of RAM).
- "Close when nobody is watching" is a switch and off by default.
- x86_64 Linux only for now; the entry doesn't show on Windows or macOS computers.
