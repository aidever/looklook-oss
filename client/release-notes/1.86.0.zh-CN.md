看看电脑端 1.86.0：手机上的终端翻看、选字跟普通网页一样；远程浏览器换内核；助理派出去的会话分权限档位。

- 手机终端往上滑翻看上文改成跟着手指走、松手有惯性，不再一顿一顿；翻看时右下角有“回到底部”。
- 手机终端里直接选文字：长按选中按住的那一整行，拖两头的把手调整范围，用系统菜单复制、分享；点两下选一个词、点三下选一行；选区跟着滚动。原来长按弹出的“选择文字”面板仍可从顶栏打开。
- 手机上只有按键条的键盘按钮会弹出输入法，点一下终端、滑动都不再弹。
- 手机上在 less、man 这类全屏程序里滑动也能上下翻了。
- 远程浏览器换成 Camoufox 内核，模拟的是一台真实记录过的电脑；按出口 IP 自动设时区、语言、定位；入口挪进工具菜单，顶上显示是哪台电脑和资源占用，常用配置一键选。
- 远程浏览器：启动时显示进度；关掉最后一个标签页不再整个退出；在别处打开时这边会提示，可以接着用；现在有声音了；通过远程连接（WebRTC）打开时画面不再断开。
- 助理派出去的会话分四档权限：只看、动手前问、项目内放手、全权，和助理自己的权限分开。助理按活挑一档，你设上限（默认项目内放手），超过的要你点头；活动面板里每个会话都能点开换档。
- 派出去的会话要你批准时，直接在助理页处理：对话上方一条“等你处理”，活动卡片里允许、本会话都允许、拒绝或回答；飞书上交代的活，审批直接发到飞书私聊。
- 助理派活只带这件活相关的原话，排队中的看看通知显示成一行小卡片。
- 返回键：手机上从助理页、新建会话页进会话，返回键和左上角箭头都回会话列表；下拉选择的弹层、快速切换按返回键能关掉。
- 电脑上会话行、文件行、对话消息有右键菜单了。
- Codex 快速模式：对话设置栏加了“快速”开关，也能用 `/fast on|off|status`；只在 ChatGPT 登录且模型有快速档时能开，否则会告诉你原因。模型设置里能改自动压缩点。
- 用量面板的上下文按自动压缩点计算，和输入框的小圆环一致，并显示最大上下文。
- 会话栏可以切“会话 / SSH”两个标签，SSH 会话按主机分组，保存的主机都列出来。
- 按项目看会话时，每个项目最多列 10 个，多的折叠成“还有 N 个”，点开就地展开。
- 手机底栏变成 助理 · 会话 · ＋ · 任务 · 我的，“我的”里不再重复列任务。
- 对话里的链接可以在看看浏览器里打开，也可以记住你的选择。
- Mermaid 图可以放大：整屏查看、滚轮或双指缩放、拖动、适应屏幕，还能复制源码或下载 SVG。
- 模型菜单统一：强度只显示该模型支持的档，Fast 收进菜单。
- 远程浏览器指纹按出口 IP 自动设时区和语言，由设备提供其余设置。
- 修复 Windows 上 SSH 保存的密码登录失败的问题。
- AI 助手的 MCP 页面远程也能查看令牌、更换令牌、安装或卸载 AI 助手；远程操作需要两步验证，不再只能在本机操作。
- 修复 Markdown 表格的首列被挤成一字一行的问题。
