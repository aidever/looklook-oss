看看电脑端 1.87.0：新增 Antigravity CLI（agy）完整支持、通用插件系统，以及多项远程连接与对话体验改进。

- 新增 Antigravity CLI（agy）完整支持：可在会话里创建和管理 agy，提供与 Claude Code / Codex 同等的原生对话界面，并在“AI 工具”页支持 MCP、Skills、一键检查更新与用量统计。
- 新增通用插件系统（“工具 → 插件”）：远程浏览器拆分为独立按需安装的插件，老版本已有的浏览器配置与数据在首次启动插件时自动迁移。
- 助理开通页在电脑还没装 Claude Code 或 Codex 时支持“一键安装”（缺 Node.js 时自动先装好，页面内直接查看步骤与进度）；批准助理审批后卡片立即刷新；客户端退出时自动停掉助理进程。
- Codex 对话在 macOS 上支持直接调用 `@Chrome` / `@Browser`；运行中支持 `⌘/Ctrl + 回车` 排队发送（也可设为默认排队）；切换模型与推理强度立即响应。
- 划词操作条改为选区上方的气泡（上方放不下时自动放下方）；切换电脑时“AI 工具 / 文件 / SSH / 本地页面 / 系统”抽屉内容自动同步切换到对应电脑。
- 远程连接支持按电脑开启“只直连”（不走 STUN/TURN，首包直接发往设备，方便配合 Clash 按 IP 的代理规则使用），并支持静态资源镜像加速。
- 开源仓库迁移至 github.com/aidever/looklook-oss。
